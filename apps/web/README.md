# @ganadito/web

Frontend web oficial de Ganadito desarrollado con **SvelteKit** y **TypeScript**.

## Estado actual
Flujo inicial V01–V06 aceptado (`docs/ACTA_ACEPTACION_V01_V06.md`): acceso y contexto,
lotes y pujas (sala en vivo con ticket de WebSocket), órdenes, mapa y Spot con ubicación
aproximada, pasaporte de trazabilidad (vista completa del dueño y vista pública del QR en
`/trazabilidad/:id/publico`). Los módulos de etapas posteriores (IA, GMX, logística,
mayorista, tributario) muestran «no habilitado» y no usan datos de demostración.
